Dotazione eqquipaggiamenti 

Prima di entrare nei dettagli individuali, è utile sapere cosa indossano e usano quasi tutti gli operatori (Jason, Ray, Clay, Sonny, ecc.) nelle missioni di azione diretta (Direct Action):

Fucile d'Assalto Standard: Heckler & Koch HK416D (con canna da 10.4 o 14.5 pollici). Nelle stagioni più recenti (dalla 6 in poi), passano al Noveske N4 in calibro .300 Blackout.

Arma da Fianco (Pistola): Glock 19 (Gen 4 o Gen 5) o Glock 17, spesso con mirini red dot (Trijicon RMR) e torce.

Casco Tattico: Ops-Core FAST (Maritime o SF) in fibra di carbonio/kevlar.

Visori Notturni (NVG): I famosi GPNVG-18 (visori panoramici a 4 tubi) o i PVS-31 a doppio tubo.

Protezione Balistica (Plate Carrier): Crye Precision AVS o JPC 2.0.

Comunicazioni: Cuffie peltor ComTac III o VI collegate a radio PRC-148 o PRC-152.

Mimetiche: Uniformi Crye Precision G3 o G4 (colorazioni Multicam, AOR1, o abiti civili per missioni sotto copertura).

🔫 Armi e Ruoli Individuali
1. Jason Hayes (Bravo 1 - Team Leader)

Arma Principale: HK416D (poi Noveske N4). Il suo setup include sempre un mirino olografico EOTech EXPS3, un magnificatore G33, un designatore laser PEQ-15 e un silenziatore Surefire SOCOM.

Secondaria: Glock 19.

Equipaggiamento: Equipaggiamento standard da assaltatore leader, leggero e versatile.

2. Raymond "Ray" Perry (Bravo 2 - 2IC / Cecchino)

Arma Principale: Oltre all'HK416, essendo spesso il cecchino/tiratore scelto (Designated Marksman) del team, usa fucili di precisione semi-automatici come il Knight's Armament SR-25 o l'HK417.

Secondaria: Glock 19.

Equipaggiamento: Porta spesso ottiche ad alto ingrandimento (Nightforce) e bipodi sui suoi fucili.

3. Sonny Quinn (Bravo 3 - Mitragliere di Supporto)

Arma Principale: Sonny è l'uomo delle armi pesanti. La sua arma iconica è la mitragliatrice leggera FN MK46 Mod 1 (5.56mm). In alcune missioni usa la MK48 Mod 1 (7.62mm) o la KAC LAMG. Per missioni che richiedono furtività (CQB), ripiega sull'HK416.

Secondaria: Glock 19.

Equipaggiamento: Il suo plate carrier è più massiccio, configurato per trasportare pesanti nastri di munizioni (belt-fed) invece di caricatori standard.

4. Clay Spenser (Bravo 6 - Assaltatore / Cecchino)

Arma Principale: Inizia come assaltatore con l'HK416, ma diventa rapidamente il secondo cecchino. Utilizza l'SR-25, il fucile d'assalto pesante FN SCAR-H e, per tiri a lunghissima distanza, il fucile a otturatore girevole-scorrevole Barrett MRAD (.338 Lapua Magnum).

Secondaria: Glock 19.

Equipaggiamento: Ottiche di precisione, telemetri laser e abbigliamento da cecchino (Ghillie suit) quando necessario.

5. Trent Sawyer (Bravo 4 - Medico di Combattimento)

Arma Principale: HK416D. In alcune operazioni lo si vede con un SIG MCX Rattler per ingombro ridotto.

Secondaria: Glock 19.

Equipaggiamento: La vera differenza di Trent è lo zaino medico tattico (spesso un Mystery Ranch o LBT), pieno di kit di primo soccorso avanzato (tourniquet, bende emostatiche, fluidi IV, siringhe di decompressione).

6. Brock Reynolds (Bravo 5 - Conduttore Cinofilo / K9 Handler)

Arma Principale: HK416D. Molto spesso utilizza anche la mitraglietta Heckler & Koch MP7A1 perché, dovendo gestire il cane con una mano, l'MP7 è più compatta e leggera da usare a una mano sola.

Secondaria: Glock 19.

Equipaggiamento: Imbracature tattiche per cani, guinzagli a sgancio rapido, videocamere montate sul dorso del cane (prima Cerberus, poi Pepper).

7. Omar Hamza (Bravo 2 - Rimpiazzo / Assaltatore nelle ultime stagioni)

Arma Principale: Essendo entrato nelle stagioni più recenti, Omar usa quasi esclusivamente il Noveske N4 in .300 Blackout.

Secondaria: Glock 19.

Equipaggiamento: Standard da assaltatore moderno, NVG PVS-31.

8. Drew Franklin (Bravo - Assaltatore Stagione 7)

Arma Principale: Noveske N4 (l'arma standard attuale del Bravo Team).

Secondaria: Glock 19.

Equipaggiamento: Setup da assaltatore standard di ultima generazione.

9. Scott Carter "Full Metal" (Alpha 1 / poi Bravo)

Arma Principale: HK416D (con setup molto simile a quello di Jason).

Secondaria: Glock 19.

Equipaggiamento: Equipaggiamento pesante e "battle-tested", identico allo standard del Bravo Team.

10. Michael Chen "Thirty Mike" (Charlie 1 / poi Bravo temporaneo)

Arma Principale: HK416D.

Secondaria: Glock 19.

Equipaggiamento: Plate carrier AVS, casco Ops-Core, standard da operatore Tier 1.

💻 Comando, Supporto e Intelligence

14. Wes Soto (Tenente / Ufficiale Esecutivo)

Arma: Glock 19.

Equipaggiamento: Simile a Blackburn. Lavorando principalmente nel TOC per gestire aspetti tattici e burocratici, raramente indossa equipaggiamento da combattimento completo a meno che non ci sia una minaccia imminente alla base.

-- Creazione del Database
CREATE DATABASE IF NOT EXISTS seal_team_armory;
USE seal_team_armory;

-- ==========================================
-- 1. CREAZIONE TABELLE
-- ==========================================

CREATE TABLE teams (
    team_id INT AUTO_INCREMENT PRIMARY KEY,
    team_name VARCHAR(50) NOT NULL,
    status VARCHAR(50) DEFAULT 'Active'
);

CREATE TABLE personnel (
    personnel_id INT AUTO_INCREMENT PRIMARY KEY,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    callsign VARCHAR(20),
    rank_title VARCHAR(100),
    role VARCHAR(100),
    team_id INT,
    status VARCHAR(50) DEFAULT 'Active',
    FOREIGN KEY (team_id) REFERENCES teams(team_id) ON DELETE SET NULL
);

CREATE TABLE equipment_categories (
    category_id INT AUTO_INCREMENT PRIMARY KEY,
    category_name VARCHAR(50) NOT NULL
);

CREATE TABLE equipment (
    equipment_id INT AUTO_INCREMENT PRIMARY KEY,
    item_name VARCHAR(100) NOT NULL,
    description TEXT,
    category_id INT,
    FOREIGN KEY (category_id) REFERENCES equipment_categories(category_id) ON DELETE CASCADE
);

CREATE TABLE personnel_equipment (
    assignment_id INT AUTO_INCREMENT PRIMARY KEY,
    personnel_id INT,
    equipment_id INT,
    usage_type VARCHAR(50), -- Es: 'Primaria', 'Secondaria', 'Tattico', 'Speciale'
    notes TEXT,
    FOREIGN KEY (personnel_id) REFERENCES personnel(personnel_id) ON DELETE CASCADE,
    FOREIGN KEY (equipment_id) REFERENCES equipment(equipment_id) ON DELETE CASCADE
);
